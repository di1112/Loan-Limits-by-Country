Loan Limits by Country

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Problem Description: 
The core objective of the "Loan Limits by Country" project is to create a model that can effectively determine suitable loan limits for individuals based on their respective countries. This project aims to leverage a diverse dataset encompassing economic indicators, demographic factors, and credit history to establish a predictive model. By establishing appropriate loan limits, financial institutions can enhance risk management, ensure responsible lending, and promote financial inclusivity.
